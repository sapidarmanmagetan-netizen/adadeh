# NARA — Digital Studio Landing Page

Website portfolio satu halaman yang ringan dan responsif.

## Struktur

```text
index.html
assets/
  css/style.css
  js/main.js
```

## Menjalankan di VS Code

1. Buka folder ini di VS Code.
2. Pasang ekstensi **Live Server** (opsional, dari Extensions).
3. Klik kanan `index.html` → **Open with Live Server**.

Tidak membutuhkan framework, npm, atau plugin wajib. Font dimuat dari Google Fonts dan sisanya merupakan HTML/CSS/JavaScript murni.
